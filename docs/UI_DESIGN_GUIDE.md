# 原有界面说明

项目沿用原有页面与视觉素材，没有建立新的统一设计系统或引入 Bencho 组件源码。原首页、角色菜单、剧情对话、成就翻面和小游戏保留各自样式。成就页只修正已解锁卡片覆盖移动端宽度、触控翻面及焦点问题。

样式主要位于 `注册and登陆/css/`、三条 `主线/*/css.css`、`成就界面/`、`玩法介绍/css/` 与各小游戏 HTML 的内联样式。当前没有全项目 Design Tokens；未来统一样式需要先确认设计方案并验证存档、剧情和移动端操作。

真实运行截图与入口说明见 [README](../README.md)，原样式和代码修复边界见 [BUGFIX_REPORT.md](BUGFIX_REPORT.md)。

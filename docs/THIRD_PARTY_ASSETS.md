## 本地账户与扫描范围

账户仍使用当前浏览器的 `localStorage`，保留原 `userArr` 结构和 `saveData_<userid>_<role>` 存档键。它是本地游戏档案机制，没有服务器账户或跨设备同步服务；旧账户与密码继续按原结构兼容。

工作区文本扫描未发现典型访问令牌、私钥或指向开发者机器的运行时绝对路径。测试内的旧 `file://` 地址是兼容性用的合成数据。扫描不覆盖 Git 历史的每个对象，也不替代素材来源核实。
